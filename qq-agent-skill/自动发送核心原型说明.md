# 自动发送核心原型（仅离线测试）

`automatic-adapter.mjs` 由宿主明确调用，不是可安装的插件，也没有修改任何 QQ Agent 源码。开关关闭时返回 `passthrough`，宿主继续原始发送；打开后将宿主已归一化的文字逐条渲染，调用当前会话的宿主发送器。图片携带原消息的引用和 @（仅第一条），用私有临时文件路径作为宿主去重键。

只提供 `file` 一种图片表示，不同时提供 `dataUrl`：此社区 fork 在 file 报错时会自动以 base64 重发，而超时也可能表示图片已经送达。只传 file 能避免该分支，但协议端需要能读取同机临时目录；远程协议端可能发不出，需要适配后测试。这个限制无法保证协议端、QQ 服务或其他宿主版本自身绝不重发。

集成宿主须提供可信的 `normalizeMessages`（与自身原始工具一致）、可信的 `render(text, privateDirectory)`、当前会话 `ctx`。渲染函数只能输出此目录下的 PNG 路径和尺寸。适配器检查真实路径、文件类型、尺寸和 PNG 头；这不是对整张图片的完整解码。单条超过 240 个 Unicode 字符，或在发送前发生任何渲染错误时，仅对该条回退原始文字并继续。临时文件只清理已验证的输出；异常时残留的临时目录需要之后人工核查。

`automatic-renderer.mjs` 的 `createRenderer({python, script})` 接受宿主管理员配置的两个绝对路径，生成上述 render 回调；无 shell，仅把 `{text}` JSON 写入 stdin。该路径不能来自 QQ 消息或模型。真实 renderer 和 Python/Pillow 需宿主单独提供；本模块不安装依赖。

返回 `completed` 表示全部发送调用已成功返回；`passthrough` 表示没有发送，宿主可执行原始工具；`rejected` 表示参数或会话无效，不应发送；`uncertain` 表示发送可能已发生或只部分发生，必须停止后续处理、不得整批重发或自动回退，避免重复。部分成功的文字分段会记录到 `session.sent`。真实 QQ、网络超时、机器人上下文看到图片而不是原始文字的影响，仍需验证。

只有宿主提供同一次运行可信的实际工具快照时，`canRedirect` 才会在开关打开且两个工具均在快照内返回 true；**现有公开 fork 的 hook 没有提供这份快照**。`automatic-prototype.mjs` 的改写演示不可直接安装。inline 调用、回复抢救、提醒和其他插件发出的文字也未覆盖。

测试：`node tests/automatic-adapter-test.mjs`。模拟 renderer 和 sender，验证开关、逐条发图、超过长度及渲染失败时文字回退、引用与 @、部分文字发送、跨会话拒绝、发送超时后不重复或继续后续条目。测试未联接真实 QQ，未实际解码或视觉验收图片。
